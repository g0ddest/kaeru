# Синхронизация просмотра через воркер и «Смотреть украдкой» — дизайн

Дата: 2026-09-26. Решения пользователя в разговоре: синхронизация для всех пользователей, хранилище
Cloudflare D1 (сначала выбран KV, затем заменён на D1 — 100 000 записей в сутки против 1000, атомарные upsert), данные — серия, озвучка, позиция; «украдкой» оставляет существующую запись на
Shikimori и только перестаёт туда писать; досмотренный тайтл удаляется из KV.

## 1. Зачем

- «Продолжить с 14:20» между телефоном, телевизором, iPad, Mac и браузером. Сейчас позиция внутри
  серии живёт только на устройстве; Shikimori знает лишь число просмотренных серий.
- Одна выбранная озвучка тайтла на всех устройствах.
- «Смотреть украдкой»: тайтл, по которому ничего не уходит в Shikimori, а прогресс всё равно общий.

## 2. Данные

Строки D1 по пользователю Shikimori (`migrations/0001_sync.sql`: positions, dubs, secrets, gone). По сети — тот же документ:

```json
{ "v": 1, "titles": { "<animeId>": {
    "dub":    { "id": 610, "title": "AniLibria.TV", "at": 1790000000000 },
    "eps":    { "<episode>": { "p": 861000, "d": 1440000, "at": 1790000000000 } },
    "secret": { "on": true, "watched": 7, "at": 1790000000000 },
    "gone":   1790000000000
} } }
```

- `at` — время изменения на устройстве (мс). Слияние поле за полем: новее `at` побеждает; позиции —
  по каждой серии отдельно. Запись с `at` старше `gone` игнорируется.
- `gone` — тайтл досмотрен и удалён: остаётся только эта метка (надгробие), чтобы старая позиция с
  другого устройства не воскресила запись. Надгробия старше 30 дней выбрасываются при записи.
- В тайтле хранится не больше 30 последних серий (по `at`).
- Никаких ников, названий аниме, токенов.

## 3. Воркер

- `GET /sync` → `{ "titles": {…} }` (без надгробий старше 30 дней).
- `POST /sync` с телом `{ "titles": { "<animeId>": { dub?, eps?, secret?, gone? } } }` → слияние
  по правилам §2, запись, ответ — итоговый документ.
- Доступ: `Authorization: Bearer <токен Shikimori>`, id — через `whoami` (кэш 10 мин). **Белый список
  не применяется**: синхронизация для любого пользователя Shikimori. 401 → `{"error":"sign_in"}`,
  недоступность Shikimori → 502 `{"error":"unavailable"}`.
- CORS — как у `/kodik/*` (сайт и localhost:5173), своя корзина лимита частоты `sync`.
- Тело не больше 256 КБ; неверная форма → 400 `{"error":"parameters"}`.
- D1-привязка `SYNC_DB`, база `kaeru-sync`. Каждое поле — один upsert «новее побеждает»,
  без чтения-перезаписи документа.

Клиенты пишут позицию на паузе, при выходе из плеера, при смене серии и раз в минуту во время
просмотра (лимит D1 бесплатного тарифа — 100 000 записей строк в сутки).

## 4. Клиенты

Общее для всех:
- При запуске и при возврате из фона (как в 5bc4943) — `GET /sync`; значения, которые новее
  локальных, применяются к локальному хранилищу позиций и озвучек.
- Запись — пакетом через `POST /sync` по правилам частоты из §3; без сети изменения копятся и
  уходят при появлении связи.
- Досмотренный тайтл (статус «Просмотрено» на Shikimori или, для «украдкой», просмотрены все
  вышедшие серии объявленного сериала) → `gone`.
- Без входа в Shikimori синхронизации нет.

«Смотреть украдкой»:
- Отдельный пункт «Украдкой» в выборе статуса тайтла (карточка тайтла, контекстные меню).
- Для такого тайтла не уходят в Shikimori ни статус, ни отметки серий, ни «добавить в список при
  старте». Прогресс — `secret.watched` в KV.
- Перевод обычного тайтла в «украдкой» не трогает запись на Shikimori — только прекращает писать.
- Перевод «украдкой» в обычный статус: ставится выбранный статус и один раз отправляется
  накопленное число серий.
- В «Мой список» — своя вкладка «Украдкой»; тайтлы участвуют в «Продолжить».

## 5. Порядок работ

1. Воркер: `/sync`, слияние, надгробия, тесты, деплой (база D1 `kaeru-sync`, миграции
   `wrangler d1 migrations apply kaeru-sync --remote`).
2. Веб. 3. Android и TV. 4. iOS, iPad и Mac. У каждого клиента свой план и свои тесты.

## 6. Проверка

- Воркер: слияние (новее побеждает, по сериям), надгробие не воскрешается старой записью, лимиты
  размера, чужой токен не видит чужой документ, 401/502, CORS.
- Клиенты: применение данных с сервера, частота записи, очередь без сети, «украдкой» не делает
  запросов к Shikimori на запись.
