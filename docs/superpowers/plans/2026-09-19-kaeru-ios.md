# Kaeru iOS Native App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить нативное SwiftUI-приложение Kaeru для iPhone и iPad с общим KMP-ядром для domain/data, авторизацией Shikimori, каталогом, Kodik-резолвом, AVPlayer и синхронизацией прогресса.

**Architecture:** `ios/` содержит только SwiftUI, UIKit/AVFoundation и iOS-адаптеры. `shared/` содержит переносимые Kotlin-модели, use cases, Ktor-клиенты и Kodik-парсер. Android сначала остаётся на текущем коде, затем подключает shared-пакеты по одному, сохраняя существующий UI и baseline-тесты.

**Tech Stack:** Kotlin Multiplatform 2.3.21, Ktor 3.6.0, kotlinx.serialization, kotlinx.coroutines, kotlinx-datetime, SKIE 0.10.14, Swift 6.4, SwiftUI, Observation, SwiftData, Keychain, AuthenticationServices, AVKit, AVFoundation, XCTest, Xcode 27.

**Spec:** `docs/superpowers/specs/2026-09-19-kaeru-ios-design.md`

## Global Constraints

- Все iOS-файлы находятся в корневой папке `ios/`, общий Kotlin-код — в `shared/`.
- Минимальная версия iOS — 17.0; обязательны iPhone compact width и iPad regular width.
- iOS UI реализуется на SwiftUI и системных iOS-компонентах; Compose Multiplatform не добавляется.
- Первый цикл не включает offline downloads, Watch Together, Chromecast/AirPlay-специфичную логику и notifications.
- `shared` не импортирует SwiftUI, UIKit, AVFoundation, Hilt, Android Context или Media3.
- Секреты не коммитятся: iOS получает client configuration из `.xcconfig`/локальной конфигурации, client secret остаётся за существующим OAuth proxy.
- Kodik-ссылки резолвятся непосредственно на устройстве воспроизведения; CDN node host не сохраняется как часть постоянной ссылки.
- Смена качества всегда создаёт новый `AVPlayerItem` и восстанавливает позицию вручную: Kodik отдаёт отдельные VOD playlists, а не master playlist.
- Каждый production-метод получает тест до реализации; для чистой конфигурации проекта проверка выполняется сборочной командой.
- Android baseline после каждого shared-изменения: `ANDROID_HOME=/Users/vitaliy/Library/Android/sdk JAVA_HOME="$(/usr/libexec/java_home -v 21)" ./gradlew :app:testDebugUnitTest --console=plain`.
- Shared baseline после каждого Kotlin-изменения: `ANDROID_HOME=/Users/vitaliy/Library/Android/sdk JAVA_HOME="$(/usr/libexec/java_home -v 21)" ./gradlew :shared:allTests --console=plain`.
- iOS simulator baseline: `xcodebuild -project ios/App/Kaeru.xcodeproj -scheme Kaeru -sdk iphonesimulator -destination 'platform=iOS Simulator,name=iPhone 17 Pro,OS=26.5' CODE_SIGNING_ALLOWED=NO build`.
